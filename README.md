# ドパBOOKs

![ドパBOOKs](assets/branding/logo-green-on-cream.png)

**読み始めるきっかけから、続きを開く瞬間まで。読書を続けたい人のための読書支援アプリ。**

デモ動画:https://youtu.be/VFz8o_5DOlw?si=rvyObBkcwNUFeDRf

## 製品概要
### 背景(製品開発のきっかけ、課題等）

「本を読みたいのに、文字ばかりのページを前にすると手が止まる」「読み始めても集中が続かない」「久しぶりに開くと、どこまで読んだか、どんな話だったか思い出せない」。

読書を続けるには、本を手に取るきっかけ、読み進めやすい環境、中断したところから戻りやすい仕組みが必要だと考えました。ドパBOOKsは、この3つの場面をつなぎ、本を最後まで読みたい気持ちを支えます。

### 製品説明（具体的な製品の説明）

ドパBOOKsは、ジャンルを問わず、小説や教材を自分に合った読み方で楽しみ、学ぶためのWeb・iPhone向け読書支援アプリです。幅広い作品・教材に読書支援を届けることを目指しています。

今回は、著作権と利用条件を考慮し、青空文庫の小説や、利用条件に沿って扱える公開教材を収録しています。これらは今回の実装・紹介で使用するコンテンツであり、アプリが目指す対象を青空文庫や特定分野の教材に限定するものではありません。

小説は紹介漫画から物語に入り、縦書きの本文を滑らかにスクロールして読めます。読みガイドが視線を導き、本文の場面に合わせたBGM・環境音・効果音が読書を演出します。中断するときは文字にしおりを挟み、再開時は読んだ範囲のふりかえりや人物相関図で内容を確認できます。

教材は「初級・中級・原文」を切り替え、図解や数式とともに学べます。今回は『微分積分学』『熱力学』『経済学のための数学』『教師のためのAI入門』を収録しています。

本棚・しおり・読書記録は端末内に保存します。Blueskyと接続すると感想を投稿でき、タイムラインで他の読者の感想にも出会えます。iPhoneのホーム画面ウィジェットからは、読書位置への移動や、読んだ内容のまとめの確認ができます。

### 特長
#### 1. 漫画と段階別の教材で、読み始めるハードルを下げる

小説の導入を漫画で紹介し、「この続きが気になる」という気持ちから原文へ進めます。今回の実装では、青空文庫の作品を題名・著者・キーワードで検索して本棚へ追加できます。

教材では、章ごとに基礎や具体例を補う初級と、定義・条件・応用を扱う中級を用意。原文PDFと行き来しながら、自分の理解に合った段階で読み進められます。図解・グラフ・公式の強調表示で、文章だけでは捉えにくい内容も確認できます。

#### 2. 読みガイドと音で、読み進める時間を支える

読みガイドが現在の文字付近を強調し、本文のスクロールも追従します。速度を調整でき、文字サイズ・書体・行間・紙面の色も自分に合わせて選べます。

小説では本文の描写をもとに音源を選び、読んでいる位置に合わせてBGMや環境音を切り替えます。読みガイドの一時停止・再開に音も連動し、場面の変化を音でも感じられるようにしました。

#### 3. 文字単位のしおりとふりかえりで、続きを開きやすくする

しおりを最後に読んだ文字へドラッグして保存できます。ページ番号だけでなく本文の文字位置を記録するため、文字サイズや画面幅が変わっても、その文字がある場所へ戻れます。

「前回から」「この章」「最初から」のふりかえりや、選んだしおりまでの人物相関図で内容を思い出せます。生成に渡す本文を読んだ範囲に限定し、先の展開を含めないようにしています。さらに、ホーム画面のウィジェットや、Blueskyと連携した感想の共有を、次に本を開くきっかけにつなげます。

### 解決出来ること

* 文字の多さに圧倒されて本を開けないとき、漫画や基礎からの説明を入口にできます。
* 自分のペースに合う読みガイドと表示設定で、読んでいる位置を追いやすくします。
* 中断後も、文字単位のしおりと読んだ範囲のまとめから再開できます。
* 小説の人物関係や教材の概念を図で確認し、理解を補いながら読み進められます。
* 感想の共有やウィジェットを通じて、日常の中に本を開くきっかけを作れます。

### 今後の展望

* 継続的な利用テストを通じて、読書の再開しやすさや、読みガイド・音の使いやすさを検証する。
* 権利者の許諾やコンテンツ提供の仕組みを整え、ジャンルを問わず幅広い小説・教材へ対応を広げる。
* AIが生成する説明・漫画・人物相関図の品質を高める。
* 本棚・しおり・読書記録の端末間同期に対応する。
* 公開運用に向けてAPIとレビュー集約の保存基盤を整え、安定した利用環境を提供する。

### 注力したこと（こだわり等）

* **読書の流れを途切れさせない操作**：小説はページの区切りを残した連続スクロールとし、読みガイドも文字の列に追従させました。しおりの操作では紙面の位置や大きさを保ちます。
* **読んだ範囲を基準にする設計**：しおり・ふりかえり・人物相関図を本文の文字位置で結び付け、AIが使う引用や位置を原文と照合しています。
* **原文に戻れる学習体験**：教材の初級・中級と元のPDFを併用でき、数式はKaTeX、対応するグラフは数値や係数から描画します。出典と利用条件も表示します。
* **作った結果を繰り返し使える仕組み**：完成した漫画・要約・教材・選曲結果を保存して再利用し、中断した生成は保存済みの内容から再開できるようにしました。

## 開発技術
### 活用した技術
#### API・データ

* OpenAI API：ふりかえりの要約、漫画の脚本・画像生成、人物関係の抽出、教材の段階別説明・図解、音の選択計画に使用。
* Freesound API：本文の場面に合う音源を検索。音源の作者・出典・ライセンスを表示。
* AT Protocol / Bluesky：OAuth認証、感想・評価の公開レコード、タイムライン、任意のBluesky投稿に使用。
* [青空文庫](https://www.aozora.gr.jp/)：公開作品一覧と、著作権フラグを確認した作品の本文を利用。
* 公開教材：[京都大学OCW](https://ocw.kyoto-u.ac.jp/)の3教材と、[名古屋大学が翻訳・公開する『教師のためのAI入門』](https://yamazato.nuee.nagoya-u.ac.jp/research/OER/AI_for_Teachers_an_Open_Textbook/)を利用。各教材の出典・利用条件は[こちら](assets/books/oej/出典.md)に記載。

#### フレームワーク・ライブラリ・モジュール

* TypeScript / React / React Native / Expo / Expo Router：WebとiPhoneの画面、画面遷移、サーバーAPIを実装。
* Expo DOM Components / React Native WebView：縦書きの紙面や教材の本文を表示。
* PDF.js / KaTeX：原文PDFと数式を表示。
* expo-audio：BGM・環境音・効果音を再生。
* AsyncStorage：本棚・しおり・設定・読書記録を端末内に保存。
* @atproto/oauth-client-browser / @atproto/oauth-client-expo：Web・アプリのOAuth認証。
* SwiftUI / WidgetKit / @bacons/apple-targets：iPhoneのホーム画面ウィジェットを実装。

#### デバイス

* PC：Webブラウザーで利用。
* iPhone：Expoの開発ビルドで利用。ホーム画面ウィジェットにも対応。

### 独自技術
#### ハッカソンで開発した独自機能・技術

* **文字位置を軸にした縦書きリーダー**：画面と文字設定に合わせて本文を実測してページを区切り、読みガイド・しおり・スクロール位置を結び付けています。表示条件が変わっても文字位置を基準に復元します。［[紙面と読みガイド](src/features/reader/VerticalPage.tsx) / [しおりと読書画面](src/features/bookmark/BookReading.tsx)］
* **読書位置に連動する音の演出**：本文にある引用位置を音の切替点に使い、背景音のクロスフェードや効果音の重ね合わせを制御します。選曲計画と再生処理を分け、読書中の移動に追従させています。［[選曲計画](src/server/music-plan.mjs) / [再生制御](src/features/music/playback.mjs)］
* **範囲を限定したふりかえりと人物相関図**：しおりまでの本文を対象に生成し、引用・文字位置・人物関係の根拠を照合します。［[要約](src/server/summary.mjs) / [人物関係の検証](src/features/characters/model.mjs) / [相関図の配置](src/features/characters/layout.mjs)］
* **章単位の段階別教材**：元PDFから抽出した章の内容をもとに、初級・中級の説明と図解を作成・保存します。本文・数式・計算によるグラフを組み合わせ、原文PDFと切り替えて読めます。［[教材生成](src/server/study.mjs) / [教材リーダー](src/features/study/StudyReader.tsx)］
* **読書の続きへつなぐウィジェット**：アプリの読書位置やまとめをウィジェットへ渡し、リンクから対応する本と文字位置を開きます。［[ウィジェット](targets/widget/Widget.swift) / [読書情報の共有](src/features/widget/bookmarks.ts)］
