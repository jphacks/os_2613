# 漫画の絵柄見本

ユーザーがこのプロジェクトへ追加するよう提供した参考漫画。最初の8枚はChatGPTで作成した漫画として提供された。追加の4枚を含め、元のPNGを加工せず保存している。

- castle-town.png：城下町
- military-camp.png：軍陣
- court-culture.png：宮中文化
- modern-school.png：近代の学校
- space-station.png：宇宙ステーション
- school-club.png：学校の部活動
- library-mystery.png：図書館の謎
- soccer-team.png：サッカー

追加の吹き出し・説明枠なしの絵柄見本：

- castle-town-art.png：城下町
- space-station-art.png：宇宙ステーション
- library-mystery-art.png：図書館の謎
- soccer-team-art.png：サッカー

共通して参照するのは、白黒の線画・読みやすい人物の表情・スクリーントーン・余白の取り方。見本の人物・服装・時代・建物・セリフ・出来事を、小説の内容へ持ち込まない。

生成時は吹き出しのないlibrary-mystery-art.pngを幅768pxに縮小したものを絵柄の参考として1枚だけ渡す。2コマ目以降は、その小説の1コマ目も人物の連続性の参考にする。12枚すべてを毎回送らない。見本の文字は生成する文字として使用しない。見本のページ内のコマ割りも再現せず、現在の方式で単一コマを生成し、アプリ側で吹き出しを組版する。保存済みの漫画はこの変更では再生成しない。

サーバーの配信時もこのディレクトリを配置する。モバイルアプリ内に見本PNGを読み込む必要はない。絵柄の方向性を共有するための資料であり、生成時間や料金の削減・絵柄の完全一致を保証するものではない。
