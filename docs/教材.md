# 教材の難易度

本棚の教材を開くと、左側に章タイトルの縦スクロール一覧、上側に「初級・中級・原文」が表示されます。左で章を選び、上で難易度を選んで読みます。初級と中級は小説と共通の読書画面（読みガイド・表示設定・しおり・ふりかえり）を使います。原文は無改変のPDFで、選んだ章の開始ページを開きます。章と難易度、章内の範囲、各段階の読書位置は端末に保存します。自分の理解に応じて段階を選ぶ方式です。

`npm run web` または `npm start` でOpenAI APIキーを入力し、学びたい章と初級または中級を選び、「この章を図解付きで作成・再開（有料）」を押してください。本文が完成済みで図解だけがない章は「この章に図解・公式を追加（有料）」と表示します。章の選択・難易度変更・原文の閲覧では生成しません。Freesoundの設定は教材生成には不要です。

章立ては元PDFのしおり、または確認済みの目次からローカルで用意します。章一覧を作るためのAI分析や、教材全文の先行分析は行いません。APIに送る本文は選択した章の範囲だけです。長い章は約6,000文字ごとに分け、同じ章内の前後各800文字を補助文脈として、その範囲の初級・中級を1回でまとめて作成します。別の章の本文は送りません。初級で基礎・用語・具体例、中級で定義・条件・応用を補います。図式や厳密な数式は原文を併用してください。AIによる説明の正しさと教育上の網羅性は生成後に確認が必要です。

選択した章の残り生成回数を画面に表示します（失敗時の再試行を含む料金上限ではありません）。各範囲は最大14,000出力トークンです。長い章ほど時間とトークンを使います。他の章には自動で進みません。サーバー起動中は新規生成最大300回・同時1件です。

停止ボタンは進行中の範囲を保存してから停止します。画面を閉じた際も、サーバーが応答を受け取れば保存します。章内の保存済み範囲はすぐ読め、再開時はその章の未作成範囲から続けます。同じ章への同時操作は同じ生成を共有します。

生成した応答は検証前に `data/study-levels/<識別子>/record.json` に保存します。識別子には元PDFのSHA-256・生成方針の版・モデル・単元を含みます。APIキーは保存しません。再起動・端末変更後もサーバー上の同じ保存データを再利用します。共同開発者と共有するには、このJSONもGitに含めてください。未完了・検証不合格の応答も再課金せず保持し、確認が必要なエラーを表示します。通信自体が失敗して応答を受け取れなかった場合は保存できません。

元教材のテキストは `data/study-sources` に、全ページから抽出したものを保存しています。PDFを変更したときは `node scripts/extract-study.mjs` を実行して更新してください。抽出はローカル処理でAPIを使いません。原作者と原文の出典・利用条件、AIによる翻案である旨は画面に表示します。派生教材も元教材の利用条件に従って扱ってください。

API形式は[OpenAI公式 Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)を使用しています。

## 数式の表示

覚える公式・定義・要点はラベル付きの枠で強調し、重要語は太字と下線で示します。導出・途中式・具体例は重要公式と同じ枠では囲みません。保存済み本文には見出しと用語の表記をもとに表示時に適用し、新規生成では重要部分と途中式を見出しで区別するよう指示します。

本文・図解・公式カードの数式はKaTeXから生成したMathMLで表示します。`x^2`、`x^{n+1}`、`e^(2x)`は上付き、`x_1`は下付きになります。`$...$`、`\(...\)`、`\[...\]`で囲まれたLaTeXの分数・総和・平方根などにも対応します。新規生成では数式の囲みを使うよう指示します。

変換は表示時だけ行い、元の教材・文字位置・しおりの保存データは変更しません。既存教材の再生成やAPI使用は不要です。解釈できない式は元の文字を残します。リンクやHTML操作の命令は許可しません。

## 図解・色分け

初級は各範囲4〜8点、中級は3〜6点を目安に、具体例・概念図・グラフ・色分け公式を作ります（各段階最大8点）。目次など図が不要な範囲では空配列にします。本文の対応する文章の後に挿入し、挿入位置の文章が一致しない保存済み図は末尾に「補足図解」として表示します。入力・変数を青、計算・関係を橙、結果を緑で示し、説明文も付けます。本文は具体例を青、注意を橙、要点・公式を緑で区別します。ダーク表示にも対応します。

グラフは生成された係数からローカルで計算してSVGで描きます。表示する式も同じ係数から組み立てるため、AIが別の式をラベルに書いた場合でもそのラベルは使用しません。二次式・一次式・指数・正弦・自然対数に対応し、任意のプログラムやHTMLは実行しません。対応しない式は公式カードや概念図を使います。原文に対するAIの式の選択や概念図の説明の正しさは、別途確認が必要です。画像生成APIは使いません。

新規教材では本文と図解を1回で生成・保存します。すでに文章がある場合は「この章に図解・公式を追加（有料）」で文章を再生成せず図解だけを追加します。旧方針で図解まで作成済みの章には「この章の図・グラフを増やす（有料）」を表示します。増補も選んだ章だけで、本文と従来の図の応答ファイルは残し、新しい図解を別に保存します。増補後の再押下・再起動では同じ結果を再利用します。追加・増補は各範囲最大12,000出力トークンです。章を開く・難易度を変えるだけでは追加生成しません。表示側の色分けは既存本文にもAPIを使わず適用します。
