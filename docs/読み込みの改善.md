# 読み込みの改善

## 本文のページ計算

全ページの文字境界を一括で同期計算せず、約6msまたは128ステップごとにブラウザーへ制御を戻す。全文の文字位置・絵文字の境界は維持する。設定変更・画面を閉じた場合は古い計測を中止し、最新の結果だけを反映する。計測中は「ページを整えています…」を表示する。文字サイズ変更後はページ番号ではなく本文位置を引き継ぐ。

総計算量やブラウザーによる最初の全文組版をなくすものではなく、計算中に画面が固まる時間を減らす改善。

## 漫画画像

生成したPNGは保存・参考画像用に残し、画面は `format=webp` で配信用画像を取得する。サーバー上のsharpで幅最大1,200px・品質82へ変換する。元画像より小さい場合だけ利用し、`.local/book-comics/` の各漫画フォルダーへ `1.preview-v1.webp` などを保存して再利用する。同じ画像への同時変換はまとめる。変換失敗時は元PNGを返し、派生画像の保存失敗時も配信は続ける。状態照会・画像変換は生成APIを呼ばない。

sharpはサーバー用の依存。配信サーバーでもlockfileに合わせて依存をインストールする。配信用画像の初回取得にはローカルの変換時間が加わる。

## 作品一覧

公式の一覧ZIPを `.local/aozora/catalog.zip` に保存し、24時間以内ならサーバー再起動後も再利用する。ZIPから現行の検証処理で作品・著作権・URLを読み取る。期限切れ・破損時は公式から再取得し、保存できない環境でも取得済み一覧で検索する。検索結果・本文の取得仕様は変更しない。

## 確認

分割計測と同期計測の結果一致、文字境界、中止、WebP変換・再利用・失敗時の表示、一覧の再起動後の再利用・期限切れ・破損をテストする。Web/iOS向けexportと、長文のWeb読書画面を確認する。実機の速度・画質は端末上での確認が必要。
