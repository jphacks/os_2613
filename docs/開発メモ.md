# ドパBOOKs（仮） 開発メモ

本を長い時間読み続けられない人が、最後まで読み切れるようにする読書支援アプリ。
iPhone（TestFlight）と Web で動かす。開発には Claude Code と Codex を使う。

## 技術構成

| 種類 | 使うもの |
|---|---|
| アプリ | Expo（expo-router）＋ TypeScript |
| iOS配布 | EAS Build / EAS Submit → TestFlight（内部テスター） |
| 縦書きの紙面 | DOM コンポーネント（'use dom'） |
| 保存 | AsyncStorage |
| パッケージ管理 | npm（依存の追加は npx expo install） |
| 開発支援 | Claude Code / Codex（同じフォルダで交互に使い、同時には動かさない） |

## 開発の進め方

各自のブランチ（keita / sota / yutaro）で作業し、合流は main だけ。プルリクエストは使わない。

1. 自分のブランチでコミットして push
2. `git fetch origin` → `git merge origin/main`（衝突はここで直す）
3. 動作確認して、自分のブランチを再度 push
4. `git switch main` → `git pull --ff-only` → `git merge 自分のブランチ` → `git push origin main`

## 禁止事項

- APIキー・パスワード・メールアドレス・Apple ID などをコミットしない
- `EXPO_PUBLIC_` で始まる環境変数に秘密の値を入れない
- `git push --force` を使わない
