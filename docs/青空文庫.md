# 青空文庫の作品を追加する

Web版の本棚から「本を追加」を開き、キーワード・タイトル・著者のいずれかで検索する。「追加」を押すと本文を取り込み、本棚へ保存する。同じ作品は重複追加しない。作品を開くと本文のプレビューと青空文庫の出典リンクを確認できる。

```sh
npm install
npm run web
```

検索には青空文庫公式の公開作品一覧を使う。作品と関係する人物の著作権フラグがすべて「なし」で、公式サイトのHTML本文を持つ作品だけを対象にする。一覧はサーバープロセス内で24時間再利用し、本文は追加した作品だけを取得する。APIキーは不要。

本棚と本文はAsyncStorageへ保存する。Webではブラウザー内、iPhoneでは端末内に残るが、別の端末には同期しない。Webの既存本棚は同じキーで引き続き読み込む。保存が無効な場合や容量が足りない場合は追加を中止し、既存の本棚を保持する。

`src/app/api/aozora+api.ts` が検索と本文取得を担当する。ブラウザーは同じサイトのAPIに接続するため、青空文庫への直接アクセスに伴うCORS制約を受けない。Webの出力形式はサーバー付きにしている。公開時にはNode.jsに対応したAPIルートのホスティングが必要で、静的ファイルのみのホスティングでは検索を利用できない。

```sh
npm test
npm run typecheck
npx expo export --platform web
```

本文は青空文庫のHTMLからプレーンテキストに変換する。ルビの読み・スクリプト・末尾の底本情報を本文から分離し、文字化けを防ぐため元の文字コードで復号する。全文ページ表示・文字しおり・ふりかえりは[しおりとふりかえり](しおりとふりかえり.md)を参照。教材検索、音声機能はこの段階では実装しない。

資料：[青空文庫の公開中作家一覧](https://www.aozora.gr.jp/index_pages/person_all.html)、[ExpoのAPIルート](https://docs.expo.dev/router/web/api-routes/)。
