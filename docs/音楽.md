# 読書中の音楽

1. VS Codeなどのターミナルで `npm start`（Webは `npm run web`）を実行します。
2. 起動時の案内でFreesound APIキーを貼り付けてEnterを押します。Windowsでは `Ctrl+V`、VS Codeでは `Ctrl+Shift+V` または右クリックで貼り付けます。キー自体は表示せず「入力: ○文字」で受け付けたことを確認できます。Client IDではなくAPI keyを使用します。空Enterなら音楽なしで起動できます。
3. 本を開き、「読書の音楽」から雰囲気を選び、「音楽を取得」を押します。
4. 候補の曲名を押し、読み込み後に「再生」を押します。曲は小さめの音量でループし、一時停止できます。

WebとiOS（Expo Go）で共通の操作です。Expo Goは開発PCのExpoサーバーへ接続してください。TestFlightなどへの配布にはAPIのHTTPS公開先の設定が別途必要です。

本を開くだけでは取得しません。OpenAI APIは使いません。本文を自動分析する選曲ではなく、指定した雰囲気からFreesoundの音楽候補を最大3曲取得する土台です。公開MP3プレビューを選択時に読み込みます。通信量が発生します。プレビューが再生できない場合は別の候補を選んでください。

CC0・CC BYの音源に絞り、作者・音源ページ・ライセンスを表示します。各音源の利用条件を確認してください。同じ雰囲気の検索結果はサーバーのメモリに1時間保存します。これは共有ファイルへの永続保存ではありません。

入力したFreesoundキーはExpoサーバーのプロセス環境だけに渡し、ファイル・アプリの保存領域・コマンド引数には書き込みません。停止後は再入力が必要です。キーを `EXPO_PUBLIC_*` に入れたり、ソースコードへ直接書いたりしないでください。`npx expo start` はこの入力処理を通らないため、通常は上記のnpmコマンドを使ってください。
