# 読書中の音楽

1. VS Codeなどのターミナルで `npm start`（Webは `npm run web`）を実行します。
2. 起動時の案内でFreesound APIキー、続いてOpenAI APIキーを入力します。Windowsでは `Ctrl+V`、VS Codeでは `Ctrl+Shift+V` または右クリックで貼り付けます。キー自体は表示せず「入力: ○文字」で受け付けたことを確認できます。FreesoundはClient IDではなくAPI keyを使用します。それぞれ空Enterで省略できます。
3. 本を開いて「本文から選曲・編集」を押します。保存済みの案があれば、APIを呼ばず共有JSONから読み込みます。
4. 初めての作品では「本文を分析して音楽取得」を押します。この操作で本文全体をOpenAIに送り、場面の解釈・雰囲気・英語の検索語を作り、Freesoundから各場面最大3曲の候補を取得します。分析と取得した候補は自動保存します。
5. 「試聴に読み込む」→「試聴を再生」で確認し、場面名・解釈・雰囲気・検索語・選択曲を編集します。「この検索語で候補を探す」はFreesoundのみを使います。変更後は「選曲案を共有保存」を押してください。
6. 雰囲気を手動で選ぶ従来の「読書の音楽」→「音楽を取得」も利用できます。

WebとiOS（Expo Go）で共通の操作です。Expo Goは開発PCのExpoサーバーへ接続してください。TestFlightなどへの配布にはAPIのHTTPS公開先の設定が別途必要です。

本を開くだけでは分析・音源取得しません。現時点では場面ごとの選曲を編集する段階で、読みガイドへの同期や自動切り替えは行いません。編集画面には未読部分も含む作品全体の解釈が表示されます。

分析は `gpt-4.1-mini` のResponses APIを使い、`store: false` と構造化出力を指定します。本文上限60,000文字、最大8場面、出力上限4,000トークンです。本文を黙って切り捨てたり、自動で分析を繰り返したりしません。1回のサーバー起動につき新規分析は最大10回、同時分析は1件です。失敗もこの回数に含みます。実際の使用トークン数を保存して画面に表示します。これは金額の上限ではないため、OpenAI側の予算設定も必要に応じて設定してください。

選曲は本文の心情・出来事を英語の音楽検索語に変え、録音名・タグの一致順で候補を選びます。声や歌、緊張・悲哀と逆の明るい曲を除外します。音そのものをAIが聴いて評価する方式ではないため、実際の適合は試聴して編集してください。候補が見つからなければ検索語を短くする、楽器名を変えるなどで再検索できます。

公開MP3プレビューは試聴の選択時に読み込みます。JSONには音源URLを保存し、MP3ファイル自体は同梱しません。試聴には通信量が発生し、音源削除などで再生できない場合は候補を探し直してください。

CC0・CC BYの音源に絞り、作者・音源ページ・ライセンスを表示します。各音源の利用条件を確認してください。同じ検索結果はサーバーのメモリに1時間保存します。

## 保存と共同開発

`data/music-plans/<本文SHA-256>.json` に分析・候補・選択曲・使用トークン数を保存します。ファイルには本文全体やAPIキーは保存しません。本文と分析形式のバージョンで照合するため、同じ本文ならアプリ再読み込み・サーバー再起動後も分析を再利用できます。Freesound取得が途中で失敗しても分析を残すため、場面の「候補を探す」からOpenAIを使わず再開できます。

**共同開発者にも再分析させないためには、生成されたJSONもGitへコミットして共有してください。** 各自のPCだけにJSONがある場合や本文が変わった場合は、新しい分析が必要になります。同じ公開サーバーを使う場合は、その保存領域を利用します。複数人が同時に編集した古い案で上書きしようとすると保存を止めます。「保存済みを読み直す」で最新版を確認してください。

入力した両APIキーはExpoサーバーのプロセス環境だけに渡し、ファイル・アプリの保存領域・コマンド引数には書き込みません。停止後は再入力が必要です。キーを `EXPO_PUBLIC_*` に入れたり、ソースコードへ直接書いたりしないでください。`npx expo start` はこの入力処理を通らないため、通常は上記のnpmコマンドを使ってください。共有ファイルへの書き込みを含む開発用APIなので、不特定多数への公開時は認証とサーバー全体の利用制限を追加してください。

API形式：[OpenAI公式 Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)
